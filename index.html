网页如何组成

三个文件配合工作

这个网站只使用了三种基本网页文件，每个文件负责一类事情。

HTML

index.html 负责网页内容，例如标题、文字和按钮。

CSS

style.css 负责网页外观，例如颜色、间距和手机端布局。

JavaScript

script.js 负责网页交互，例如菜单展开和文字切换。
